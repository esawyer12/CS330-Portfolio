# CS330-Portfolio


Project Reflection and Portfolio


Software Design Approach

I approach software design by prioritizing modularity, user experience, and scalability from the very beginning. While working on this project, I significantly sharpened my skills in 3D planning, asset optimization, and efficient scene-graph management.

My design process followed a structured lifecycle:
• Conceptualization: Sketching the 3D layout and defining visual hierarchies.
• Prototyping: Blocking out primitive shapes to test scale and camera angles.
• Refinement: Replacing placeholders with complex geometry, custom textures, and dynamic lighting.
These tactics—especially breaking complex visual scenes into isolated, manageable components—can be directly applied to future work in software architecture, UI/UX design, and any object-oriented programming task.

Program Development & Evolution

My approach to developing programs relies heavily on incremental builds and rigorous testing. Developing this 3D scene required me to adopt new strategies, such as managing vertex buffers, implementing custom shaders, and calculating complex transformation matrices.
Iteration was the backbone of my development workflow. I constantly adjusted lighting parameters, material properties, and mesh alignments based on real-time rendering feedback. Throughout the project milestones, my coding approach evolved from writing monolithic, trial-and-error scripts to designing clean, modular functions. This evolution allowed me to systematically isolate bugs and smoothly scale the project to its final, completed state.

Future Applications in Computer Science

Computer science is a foundational tool that will help me achieve my goals by enabling me to solve complex, data-driven problems efficiently. Mastering computational graphics and visualizations equips me with unique technical advantages:
• Educational Pathway: It strengthens my spatial reasoning, deepens my understanding of linear algebra, and builds a strong foundation for advanced studies in computational geometry or data science.
• Professional Pathway: It opens doors to high-demand industries like simulation software development, virtual reality, data visualization UI, and interactive media design.
The ability to translate abstract code into meaningful visual context is a highly versatile skill that will remain relevant across my entire career.
